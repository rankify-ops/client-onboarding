EV Charging

EV Charger Installation, Done Properly

Plugging an EV charger into the wrong circuit is a common — and dangerous — shortcut. We assess your switchboard's capacity and install a dedicated circuit sized for the charger.

We install home EV charging for homeowners across Geelong and the Bellarine Peninsula, and can pair the install with a switchboard upgrade if your board needs it.

Every EV charger install is tested and certified, with a fixed price agreed before we start.
